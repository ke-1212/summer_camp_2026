# summer_camp_2026 (夏合宿 2026 ネタ置き場)

夏合宿 2026 で使うミニゲームと、その下調べの置き場。
第一弾は、わざと使いにくくした入力欄で指定の値を合わせ続けるブラウザゲーム「ワースト・ボリューム選手権」。

## ディレクトリ構成

```text
summer_camp_2026/
├── README.md
├── index.html                  Pages のトップ。worst-volume/ へ転送するだけ
├── .github/workflows/pages.yml main への push で GitHub Pages に公開
├── docs/
│   └── weird-ui-research.md    変なUI・bad UI battles の調査記録（ネタ出しの元資料）
└── worst-volume/
    └── index.html              ワースト・ボリューム選手権（1ファイル完結）
```

## 遊び方

公開先は `https://ke-1212.github.io/summer_camp_2026/`。スマホでそのまま開ける。

手元で動かす場合は `worst-volume/index.html` をブラウザで直接開けば動く。ビルド・依存ライブラリなし。

```bash
cd worst-volume
python3 -m http.server 8000  # PC のブラウザで http://localhost:8000/ を開く
```

- スマホ縦持ち前提（PC でも動く）
- 効果音あり。最初に「はじめる」をタップした時点で音が有効になる
- 「叫ぶ」「水準器」はタイトル画面のボタンでマイク・傾きセンサーを許可した場合だけ出題される
- マイク・傾きセンサーは https か localhost でしか使えない。
  スマホから `http://<PC の IP>:8000/` で開いた場合は使えないので、Pages の URL で試す

## ワースト・ボリューム選手権

お題は「指定の値に合わせろ」だけ。変わるのは入力欄のほう。
1本 8 秒、時間切れの瞬間の値が目標の許容誤差内なら成功。ライフ 4、5 ステージごとに許容誤差が狭まる。

### お題

| お題 | 指示文の例 | 範囲 |
|---|---|---|
| 音量 | 音量を **70** にしろ！ | 0〜100 |
| 予約日 | 予約日を **10/14** にしろ！ | 2026年10月1〜31日 |
| 支払い | **¥6,480** を払え！ | ¥0〜¥9,999 |
| 評価 | **★3.5** をつけろ！ | ★0〜5（0.5刻み） |

- 目標は各お題の範囲の 30〜90% から出る（ランチャーの最短飛距離が約 29% のため）
- 許容誤差は範囲の 5% から始まり、5 ステージごとに 1% ずつ狭まって最小 2%

### 入力欄

| 入力欄 | 不便さの分類 | 出るお題 | 挙動 |
|---|---|---|---|
| ランチャー | 再現性がない | 全部 | 長押しで砲身の角度と初速が上がり、離すと発射。着弾した位置が値 |
| ルーレット | 再現性がない | 全部 | マスの数字はでたらめな並び。タップで回し、止まったマスが値 |
| 押すたびランダム | 再現性がない | 全部 | 押すたびにでたらめな値 |
| 16連サイコロ | 再現性がない | 音量 | 出目の合計が音量。タップで固定、「振る」で残りを振り直す |
| 物理スライダー | 精度が出ない | 全部 | つまみが中央に引かれるバネ付き。離すと揺れ続けて止まらない |
| カーリング | 精度が出ない | 全部 | 石を上に払う。止まった位置が値。奥の線を越えると場外で 0 |
| 日めくり | 精度が出ない | 予約日 | 上に払ってめくる。速いほど何枚もめくれる。めくった紙は戻らない |
| 水準器 | 精度が出ない | 全部 | 端末を左右に傾けて気泡を合わせる（傾きセンサーの許可が必要） |
| 空気入れ | 操作量が多い | 全部 | 押すと上がるが常に抜けていく。押し続けないと保てない |
| 全部ラジオボタン | 操作量が多い | 全部 | 範囲の値を全部ラジオボタンで並べる（音量なら 101 個） |
| 円周率スクロール | 操作量が多い | 音量 | 円周率の小数を横に流し、枠に入った 2 桁が音量 |
| シャッフル・テンキー | 操作量が多い | 支払い | 押すたびにキーの並びが入れ替わる |
| 叫ぶ | 社会的コストが高い | 全部 | 声の大きさが値（マイクの許可が必要） |

不便さの分類は `docs/weird-ui-research.md` §6 の4分類による。

### 入力欄の追加方法

`worst-volume/index.html` の `CONTROLLERS` 配列に1要素足すだけで出題に加わる。
入力欄は 0〜100 の「位置」を返すだけでよく、お題ごとの単位への変換（音量・日付・金額・星）はゲーム側が行う。

```js
{
  id: "my-controller",        // 一意な ID
  name: "表示名",
  pain: "effort",             // effort / precision / randomness / social
  topics: ["volume"],         // 出すお題を絞るとき（省略すると全お題）
  mount(root, { topic, target, onChange }) {
    // root に操作面を描画し、位置 (0〜100) が変わるたびに onChange(位置) を呼ぶ
    // 目盛りのラベルは topic.format(値) でお題の単位にできる
    // 判定・タイマー・ライフは親側が持つので、ここでは気にしない
    return () => { /* 後始末（イベント解除・requestAnimationFrame の停止） */ };
  }
}
```

作った入力欄だけを繰り返し試すときは、URL に `?only=<id>`（お題も固定するなら `&topic=<お題の id>`）を付ける。

```bash
open "http://localhost:8000/?only=my-controller&topic=date"  # お題の id: volume / date / money / star
```

- 実際の端末音量は変えない。値はゲーム内の数値として扱う
