# summer_camp_2026 (夏合宿 2026 ネタ置き場)

夏合宿 2026 で使うミニゲームの置き場。
第一弾は、わざと最悪にした登録手続きを最後まで突破するブラウザゲーム「Bad UI選手権」。

## ディレクトリ構成

```text
summer_camp_2026/
├── README.md
├── index.html                  Pages のトップ。worst-volume/ へ転送するだけ
├── .github/workflows/pages.yml main への push で GitHub Pages に公開
└── worst-volume/
    └── index.html              Bad UI選手権（1ファイル完結）
```

`worst-volume/` は以前の「音量を合わせる」ミニゲームの名残の名前。しおりの QR が指す公開 URL を変えないため、そのままにしている。

## 遊び方

公開先は `https://ke-1212.github.io/summer_camp_2026/`。スマホでそのまま開ける。

手元で動かす場合は `worst-volume/index.html` をブラウザで直接開けば動く。ビルド・依存ライブラリなし。

```bash
cd worst-volume
python3 -m http.server 8000  # PC のブラウザで http://localhost:8000/ を開く
```

- スマホ縦持ち前提（PC でも動く）
- 最後まで突破するとかかった時間が出る。制限時間はなし
- マイク・傾きセンサーは https か localhost でしか使えない。
  スマホから `http://<PC の IP>:8000/` で開いた場合は使えないので、Pages の URL で試す

## Bad UI選手権

アカウント登録を完了させるだけの1本道。全11ステップ。

| # | ステップ | 何が最悪か |
|---|---|---|
| 1 | アカウント登録をはじめる | 大きく目立つボタンは全部偽物。本物は隅の極小リンク |
| 2 | Cookie の同意 | 二重否定のチェック。「同意して次へ」が3回逃げる |
| 3 | メールアドレス | 確認欄は貼り付け禁止、文字が右から左に並ぶ |
| 4 | パスワード作成 | 条件を満たすたびに次の条件が増える |
| 5 | 生年月日 | 年・月・日を全部ラジオボタンで並べる（170 個） |
| 6 | 通知音量 | 物理スライダー。離すと揺れて止まらない |
| 7 | 着信音量 | 空気入れ。押さないと値が抜けていく |
| 8 | アラーム音量 | 円周率スクロール。枠に入った 2 桁が値 |
| 9 | CAPTCHA | 回を追うごとにタイルが増え、絵柄が動く。2 回はやり直しさせられる |
| 10 | 利用規約 | 最後まで読まないと同意できない。途中で 3 回スクロールが戻る |
| 11 | 送信 | 確認ダイアログが 3 回。最後の 1 つだけ「いいえ」が正解 |

- 進捗バーは進んだり戻ったりし、完了まで 99% を超えない
- 乱数で結果が決まる仕掛けは入れていない（理不尽でも、突破口は必ずある）

### 音量ステップの入力欄を差し替える

6〜8 の音量ステップは、URL の `?ctrl=` で入力欄を差し替えられる。

| `ctrl=` | 入力欄 | 何を合わせるか |
|---|---|---|
| `physics-slider` | 物理スライダー | 音量 |
| `pump` | 空気入れ | 音量 |
| `pi` | 円周率スクロール | 音量 |
| `curling` | カーリング（石を払って止まった位置） | 音量 |
| `keypad` | シャッフル・テンキー（押すたびにキー配置が変わる） | 月額料金 |
| `tearoff` | 日めくり（めくった紙は戻らない） | 利用開始日 |
| `shout` | 叫ぶ（声の大きさ。マイクの許可が必要） | 音量 |
| `level` | 水準器（端末の傾き。傾きセンサーの許可が必要） | 音量 |

### ステップの追加方法

`worst-volume/index.html` の `STEPS` 配列に1要素足すだけで手続きに加わる。

```js
{
  id: "my-step",               // 一意な ID
  title: "画面の見出し",
  pain: "effort",              // 不便さの分類（effort / precision / visibility / dark-pattern など）
  mount(root, { done }) {
    // root に画面を描画し、突破条件を満たしたら done() を呼ぶ
    // 進捗バー・時間・画面遷移は親側が持つので、ここでは気にしない
    return () => { /* 後始末（イベント解除・requestAnimationFrame の停止） */ };
  }
}
```

作ったステップだけを試すときは、URL に `?only=<id>` を付ける。

```bash
open "http://localhost:8000/?only=my-step"             # ステップを1つだけ
open "http://localhost:8000/?only=vol-notify&ctrl=keypad"  # 音量ステップの入力欄を差し替え
```
