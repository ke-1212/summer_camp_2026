# 共有ランキングの設定

参加者全員の記録を1つのランキングにまとめるための手順です。Google スプレッドシートと Apps Script を使います。
**設定しなくても遊べます**（その場合、ランキングはその端末の中だけに保存されます）。

## 手順

1. Google スプレッドシートを新規作成する（名前は何でもよい）。
2. メニューの **拡張機能 → Apps Script** を開く。
3. 既定の `コード.gs` の中身を、このフォルダの [`ranking.gs`](ranking.gs) の中身で置き換えて保存する。
4. 右上の **デプロイ → 新しいデプロイ** を選ぶ。
   - 種類: **ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/……/exec`）をコピーする。
6. [`config.js`](config.js) を開き、URL を貼る。

   ```js
   window.YASUINE_RANKING_URL = "https://script.google.com/macros/s/……/exec";
   ```

7. 変更を push すると、GitHub Pages 側にも反映される。

## 動きの確認

- ブラウザで URL に `?action=list` を付けて開き、`[]` か記録の JSON が返ればサーバー側は動いています。
- ゲームを1回クリアし、完了画面でニックネームを入れて「登録」を押すと、スプレッドシートに1行増えます。

## 仕様

- 保存される内容: 日時・ニックネーム（12文字まで）・所要秒数・支払総額・実績数・ミッション成功かどうか。
- 個人情報は保存しません。ニックネームは参加者が自分で入力したものだけです。
- 記録の取得・送信はすべて非同期で行うため、通信が遅くてもゲームは止まりません。
- 送信に失敗した場合も、記録はその端末の `localStorage` に残ります。
- 誰でも書き込める URL なので、合宿が終わったらデプロイを無効化することをおすすめします。
